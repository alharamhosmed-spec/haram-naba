# متقن لإدارة المشاريع - نبض

**اللوحة التنفيذية الحية** لكل أنظمة **متقن لإدارة المشاريع** (Mutqan Project Management) بمستشفى الحرم:
حضوري · رصد · بلاغ · نقاء · رقمك · عُهدة · وثّق — رسوم متحركة حيّة، وتحتها القراءة والمدى، من بيانات الأنظمة الفعلية فقط.

غلاف تطبيق (PWA) بنفس «نمط التطبيق» — يتثبّت على أندرويد وآيفون والكمبيوتر بأيقونة النبض ويفتح بشاشة كاملة.

**رابط التطبيق:** `https://alharamhosmed-spec.github.io/haram-naba/`

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي · مستشفى الحرم

## كيف يشتغل
- اللوحة جزء من **بوابة متقن** (Google Apps Script) وتفتح من رابطها بـ `?board=1`.
- الغلاف يفتح: `GAS_URL?app=1&board=1` — والدخول بنفس رمز البوابة.
- لا يخزّن الغلاف أي بيانات — كل الأرقام مباشرة من الأنظمة.

## الإعداد
1. بوابة متقن **v2.2.0 أو أحدث** (فيها `Naba_Board.gs` + `Naba_Board_UI.html`).
2. النشر: التنفيذ باسم **أنا** · الوصول **أي شخص**.
3. رابط `/exec` حق البوابة في `index.html` → `GAS_URL` (و`FIXED: { board: '1' }` ثابت).

## التحديثات
- تعديل اللوحة نفسها: انشر البوابة كـ **New version على نفس النشر** — ما تحتاج تلمس GitHub.
- تعديل الغلاف: عدّل الملف وزِد `VERSION` في `sw.js`.
- الأيقونة: `python3 tools/make_icons.py pulse`
